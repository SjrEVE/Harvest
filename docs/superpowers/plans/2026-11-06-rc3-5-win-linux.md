## Constraints and decisions

- Base: db52e67 / installed runtime 1b70185; preserve migrations 1–5, semantic HSMT parser, replay and attempt telemetry. Never overwrite with the older 2a47b16 implementation.
- Existing DateField.qml and test_date_field_navigation.py are user work; preserve their content and verify them with the final tree.
- Default to missing-only collection; deliberate refresh/reconcile remains available as an explicit action. Do not change the running production configuration or root in this build task.
- An additive migration sets existing automatic reconcile/deep TTL refresh to opt-in under the new missing-only policy, retaining previous config in an audit setting and keeping raw/proofs/holds/jobs unchanged. Retrying unproven failed windows remains allowed.
- Shutdown preserves pending work on both platforms. STOP_GRACEFUL cancels only a specified task; PAUSE/RESUME remain durable. Previously explicit cancellation is not resurrected.
- DETAIL and REOFFER retain their public interfaces, but reuse verified identical endpoint/body/listing captures rather than fetching twice. Document-only/unsupported captures must not cause a fetch loop.
- Snapshot publication remains atomic and single-writer; coalesce background publications by count/time and flush pending changes on idle exit/shutdown. Never import Qt/serving code into Linux.
- Package version 0.0.1-RC3-5 / 0.0.1rc3.post5 / Debian 0.0.1~rc3-5. Build hashes must include new untracked source modules and fail if inputs drift.
